# CSE_3241_Team_Project
Four-person team project: a relational bookstore database built with SQL/SQLite, including schema design, normalization, joins, views, indexes, and data management.

## Submissions
1. Final Project Report Document:
PDF document that contains the final project report

2. Checkpoints Folder:
Contains the checkpoints submitted throughout the semester

3. DatabaseCreation Folder:
— The Bookstore.txt file: contains the create statements for the database, views, and indexes
— InsertStatements folder: contains .txt files for the insert statements for each relation in the database. If the database file is corrupted, copy pasting these in DataGrip should recreate the database. 
— InsertStatementsSQLFormat: contains the .sql files version of the insert statements for each relation. These can also be used to recrete the database

4. RawData Folder:
Contains .txt files that have the raw data used for each relation. The values are comma separated with each tuple on a new row

5. SampleSQLStatements Folder
SampleQueries.txt file: Contains the sample queries for the database. Copy pasting them in the DataGrip should run the queries
DeleteStatements.txt file: Sample delete statements from the final project report document
InsertStatements.txt file: Sample insert statements from the final project report document

6. Bookstore.sqlite
SQLite binary for the database
